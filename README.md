## ⬇️ ดาวน์โหลด & ติดตั้ง

1. โหลด `Ballcar PDF.exe` จาก **[หน้า Releases](https://github.com/ballcar/Ballcar-PDF/releases/latest)**
2. ดับเบิลคลิกเปิดได้เลย — ไฟล์เดียวจบ ไม่ต้องติดตั้ง Python
3. ครั้งแรก Windows SmartScreen อาจเตือน → กด **"ข้อมูลเพิ่มเติม" → "เรียกใช้ต่อไป"** (เพราะยังไม่ได้เซ็นใบรับรอง)

> 💡 ฟีเจอร์ **OCR** ต้องติดตั้ง Tesseract แยก (ดูหัวข้อ "ติดตั้ง OCR" ด้านล่าง)

## เวอร์ชัน
เก็บที่ `version.json` — `build-exe.ps1` จะ **เพิ่มเลขให้อัตโนมัติทุกครั้งที่ build**

กติกา: patch +1 ไปเรื่อยๆ ถึง .99 แล้วปัดขึ้น minor
```
1.0.1 → 1.0.2 → … → 1.0.99 → 1.1.0 → 1.1.1 → …
```
ดูเวอร์ชันได้ที่ชื่อหน้าต่าง และเมนู ช่วยเหลือ → เกี่ยวกับโปรแกรม

## ภาษา (ไทย / English)
เมนู **ภาษา / Language** → เลือกไทยหรือ English — เปลี่ยนทันทีไม่ต้องปิดโปรแกรม
โปรแกรมจำภาษาที่เลือกไว้ให้ (เก็บที่ `%APPDATA%\BallcarPDF\settings.json`)
ข้อความอยู่ที่ `app/i18n.py` — เพิ่ม/แก้คำแปลได้ที่นั่น

Python 3.12 + PySide6 + PyMuPDF

## วิธีเปิดโปรแกรม
ดับเบิลคลิก `เปิดโปรแกรม.bat`

หรือจากเทอร์มินัล:
```
.venv\Scripts\python.exe -m app.main
```

## ติดตั้งใหม่ (เครื่องอื่น)
```
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## ความสามารถ (เฟส 1 — เสร็จแล้ว)
| ทำได้ | วิธีใช้ |
|-------|--------|
| เปิด/อ่าน PDF | ไฟล์ → เปิด (Ctrl+O) — ไฟล์มีรหัสจะถามรหัสผ่านให้ |

| **ย้อนกลับ / ทำซ้ำ** | **Ctrl+Z / Ctrl+Y** (ย้อนได้ 20 ขั้น) |
| เลื่อนหน้า / ซูม | PgUp/PgDn, Ctrl+ล้อเมาส์, ปุ่ม "พอดีความกว้าง" |
| ดูข้อความในหน้า | มุมมอง → แสดงข้อความในหน้า |
| ค้นหาคำ + ไฮไลต์ชั่วคราว | ช่องค้นหาบนแถบเครื่องมือ, F3 = จุดถัดไป |
| **ไฮไลต์ข้อความ (ถาวร)** | ปุ่ม 🖍 ไฮไลต์ → ลากคลุมข้อความ → เลือกสีได้<br>คลิกที่ไฮไลต์เพื่อลบ · ล้างทั้งหน้า · Esc ออก · Ctrl+Z ย้อน |
| แทรกหน้าว่าง / แทรกไฟล์ PDF อื่น | เมนู จัดการหน้า |
| ย้ายลำดับหน้า | **ลากหน้าขึ้น-ลงที่แถบ thumbnail ซ้ายได้เลย** หรือ Ctrl+Shift+ลูกศรขึ้น/ลง |
| ลบหน้า | **คลิกขวาที่หน้า → ลบ** หรือกด Delete |
| หมุนหน้า | **คลิกขวาที่หน้า → หมุนซ้าย/ขวา/180°** |
| รวมไฟล์ PDF | เครื่องมือ → รวมไฟล์ PDF |
| แยกไฟล์ตามช่วงหน้า | เครื่องมือ → แยกไฟล์ (พิมพ์ `1-3,5,8-10`) |
| เพิ่มเลขหน้า | เครื่องมือ → เพิ่มเลขหน้า (เลือกตำแหน่ง+รูปแบบ) |
| บันทึกหน้าเป็น .jpg / .png | เครื่องมือ → บันทึกหน้าเป็นรูป (เลือก DPI) |
| **OCR อ่านไฟล์สแกน (ไทย/อังกฤษ)** | เครื่องมือ → OCR — ได้ทั้ง "PDF ที่ค้นหาข้อความได้" หรือ "ไฟล์ .txt"<br>⚠️ ต้องลง Tesseract ในเครื่องก่อน (ดูหัวข้อล่าง) |
| **แปลงเป็น Word (.docx)** | เครื่องมือ → แปลงเป็น Word (คงตาราง/รูป/ข้อความไทย) |
| **ดึงตารางเป็น Excel (.xlsx)** | เครื่องมือ → ดึงตารางเป็น Excel (1 ตาราง = 1 ชีต) |
| **ดึงรูปภาพในไฟล์ออกมา** | เครื่องมือ → ดึงรูปภาพในไฟล์ (รูปที่ฝังอยู่จริง ไม่ใช่ภาพทั้งหน้า) |
| ดึงข้อความทั้งไฟล์เป็น .txt | เครื่องมือ → ดึงข้อความทั้งไฟล์ |
| ใส่ลายน้ำข้อความ (ไทย/อังกฤษ) | เครื่องมือ → ใส่ลายน้ำข้อความ (เลือกความเข้ม/องศาเอียง/หน้าไหน) |
| ใส่ลายน้ำจากรูป | เครื่องมือ → ใส่ลายน้ำจากรูป |

| **แก้ข้อความเดิมในไฟล์** | ปุ่ม ✏ แก้ข้อความเดิม → คลิกข้อความ → ลบของเดิม เด้งกล่องเติมคำเดิมให้แก้<br>คงสี/ขนาดเดิม · ไฟล์สแกนต้อง OCR ก่อน · ได้ผลดีบนพื้นขาว |
| **กรอกแบบฟอร์ม PDF** | เครื่องมือ → กรอกแบบฟอร์ม → กรอกทุกช่องใน dialog<br>"กรอก (แก้ต่อได้)" คงเป็นฟอร์ม · "กรอกแล้วตรึง" แนะนำสำหรับไทย (ช่องฟอร์มมาตรฐานไม่มีฟอนต์ไทย) |
| ใส่ลายเซ็น / ตราประทับ | เครื่องมือ → ใส่ลายเซ็น → เลือกรูป (.png .gif .jpg …) → **ลากย้าย / ลากมุมย่อขยาย** → Enter หรือดับเบิลคลิก (Esc ยกเลิก) |
| **แก้ลายเซ็นที่วางแล้ว** | **ดับเบิลคลิกที่ลายเซ็น** → ย้าย/ย่อขยายได้เลย (หรือคลิกครั้งเดียวแล้วใช้ปุ่มบนแถบเหลือง / กด Delete เพื่อลบ) — แก้ได้เรื่อยๆ จนกว่าจะกดบันทึก |
| **คลังลายเซ็น** | ปุ่ม **✒ ลายเซ็น** บนแถบเครื่องมือ → คลิกชื่อลายเซ็นที่เก็บไว้ = วางได้เลย<br>เก็บเข้าคลัง: "➕ เพิ่มลายเซ็นเข้าคลัง" หรือปุ่ม "💾 เก็บเข้าคลัง" ตอนเลือกลายเซ็นอยู่<br>ไฟล์เก็บที่ `%APPDATA%\BallcarPDF\signatures` |
| พื้นหลังลายเซ็น | ลบพื้นขาวออกให้อัตโนมัติ (เส้นตาราง/ข้อความใต้ลายเซ็นจะไม่ถูกบัง) |
| พิมพ์ไปเครื่องพิมพ์ | ไฟล์ → พิมพ์ (Ctrl+P) เลือกเครื่องพิมพ์/ช่วงหน้าได้ |

เลือกหลายหน้าพร้อมกันได้ที่แถบ thumbnail ด้วย Ctrl+คลิก หรือ Shift+คลิก

## ติดตั้ง OCR (ทำครั้งเดียวต่อเครื่อง)
ฟีเจอร์ OCR เรียกใช้โปรแกรม Tesseract ที่ติดตั้งในเครื่อง (ไม่ได้รวมมาใน .exe)
```
winget install -e --id UB-Mannheim.TesseractOCR
```
แล้วดาวน์โหลดชุดภาษาไทยไปวางไว้ที่ `C:\Program Files\Tesseract-OCR\tessdata\`
```
https://github.com/tesseract-ocr/tessdata/raw/main/tha.traineddata
```
เครื่องนี้ติดตั้งครบแล้ว — เครื่องอื่นที่เอา .exe ไปใช้ต้องทำขั้นตอนนี้ด้วย
(ถ้าไม่ทำ เมนู OCR จะขึ้นข้อความบอกวิธีติดตั้งให้)

## ข้อจำกัดที่ควรรู้
- **ดึงตาราง** หาจากเส้นตาราง — ถ้าเป็นไฟล์สแกน หรือตารางไม่มีเส้น จะหาไม่เจอ
- **ลายเซ็น** แก้ไข/ย้ายได้จนกว่าจะกดบันทึก บันทึกแล้วฝังถาวร
- **แปลงเป็น Word** คงหน้าตาได้ระดับหนึ่ง แต่เอกสารซับซ้อนมากอาจเพี้ยนบ้าง

## ทดสอบ
```
.venv\Scripts\python.exe smoke_test.py     # ตรรกะ PDF
set QT_QPA_PLATFORM=offscreen
.venv\Scripts\python.exe test_reorder.py   # ลากสลับลำดับหน้า
.venv\Scripts\python.exe test_ui.py        # เมนูคลิกขวา
.venv\Scripts\python.exe test_undo.py      # ย้อนกลับ/ทำซ้ำ
.venv\Scripts\python.exe test_watermark.py # ลายน้ำ/ลายเซ็น
.venv\Scripts\python.exe test_placement.py # ลากย้าย/ย่อขยายลายเซ็น
.venv\Scripts\python.exe test_stamp_edit.py # แก้ลายเซ็นที่วางแล้ว + .gif
.venv\Scripts\python.exe test_library.py   # คลังลายเซ็น
```

## โครงสร้าง
- `app/pdfops.py` — ตรรกะ PDF ทั้งหมด (ไม่พึ่ง UI)
- `app/viewer.py` — วิวเออร์แสดงหน้า + ไฮไลต์
- `app/main.py` — หน้าต่างหลัก เมนู แถบเครื่องมือ พิมพ์
